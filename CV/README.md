# Sample CV (HTML & CSS)

This repository contains a **sample CV (Curriculum Vitae)** designed and developed by me using **HTML and CSS**.  
The project was created for practice purposes and to improve web design and layout skills.

## 📄 Project Files
- `index.html` – Structure of the CV
- `styles.css` – Styling and layout of the CV

## 🎯 Project Purpose
- Practice HTML5 semantic elements
- Improve CSS styling and layout techniques
- Create a clean and professional CV design
- Learn how to structure personal information on a webpage

## 🛠 Technologies Used
- HTML5
- CSS3

## 🚀 How to View
1. Clone or download the repository
2. Open `index.html` in any modern web browser

## 📌 Notes
- This is a **sample CV**, not a real resume
- Content is for demonstration and learning purposes
- No JavaScript is used in this project
