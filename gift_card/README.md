# FreeCodeCamp HTML & CSS Project

This project was created as part of a **FreeCodeCamp** learning exercise.  
It is built using basic **HTML** and **CSS** to practice frontend structure and styling.

## 📄 Project Files
- `index.html` – Contains the HTML structure of the project
- `styles.css` – Contains all the CSS styles used in the project

## 🎯 Purpose
- Practice HTML5 markup
- Learn CSS styling and layout
- Complete FreeCodeCamp project requirements
- Improve frontend development skills

## 🛠 Technologies Used
- HTML5
- CSS3

## 📚 Learning Platform
This project is part of the curriculum on **[FreeCodeCamp.org](https://www.freecodecamp.org/)**.

## 🚀 How to Run
1. Download or clone the repository
2. Open `index.html` in any web browser

## 📌 Notes
- This project is for educational purposes
- No JavaScript is used
- Built by following FreeCodeCamp guidelines
